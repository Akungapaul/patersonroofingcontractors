Create `scripts/utils/reporter.ts`:
- Export `interface AuditResult { category: string; status: 'PASS' | 'FAIL' | 'WARN'; message: string; details?: string[] }`
- Export `function printResults(results: AuditResult[]): void` that:
  - Prints header: `=== Audit Results ===`
  - Counts: `PASS: N | WARN: N | FAIL: N`
  - For each result: `[OK] category: message` or `[!!] category: message` or `[XX] category: message`
  - If result has details, prints each indented: `     detail`
  - Calls `process.exit(1)` if any FAIL results, `process.exit(0)` otherwise

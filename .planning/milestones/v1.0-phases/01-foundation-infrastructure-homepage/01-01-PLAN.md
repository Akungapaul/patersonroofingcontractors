Create directory `public/theme-variations/` and generate 10 standalone HTML files. Each file must be a complete, self-contained HTML page (no external dependencies -- inline all CSS, load Cormorant and Cormorant Garamond from Google Fonts CDN via link tag).

All 10 variations use the same base palette:
- Navy primary: #1B2A4A (per D-09)
- Amber accent: #D97706 (per D-10)
- White: #FFFFFF, Gray-light: #F8FAFC (per D-11)
- Navy-light: #2A3F6A, Navy-dark: #111D35, Amber-light: #F59E0B, Amber-dark: #B45309

Each HTML file must render a mock homepage showing:
1. A sticky header bar (navy background, white text, amber phone CTA button)
2. A hero section (navy overlay on a gray placeholder, white H1 "Passaic County's Trusted Roofing Contractors" in Cormorant font, amber CTA button "Get Free Estimate")
3. A mid-page CTA bar (navy background, white text, amber inline button)
4. A 3-column services grid with icon-placeholder cards (white bg, shadow, hover states shown via CSS)
5. A "Why Choose Us" section (gray-light background) with trust badge icons and 4 stat counters
6. A municipality grid (4 columns, cards with cluster tags)
7. A testimonial row (3 cards, amber star ratings, name + city)
8. An emergency CTA banner (amber background, white text, white CTA button)
9. A contact form section (2-column: form fields left, contact info right)
10. A footer (navy background, 4 columns, navy-dark bottom bar)

The 10 variations explore these dimensions (label each variation at the top of the page with its variation number and description):

- **Variation 1:** Baseline -- exact colors from D-09/D-10, shadow-sm cards, rounded-lg, 80px section spacing, standard amber buttons
- **Variation 2:** Higher contrast -- navy-dark (#111D35) hero overlay instead of navy, bolder amber (#E88A00) accent, stronger card shadows (shadow-md default)
- **Variation 3:** Softer/lighter -- navy at 85% opacity hero overlay, lighter amber-light (#F59E0B) for buttons, shadow-xs cards, more white space (96px section spacing)
- **Variation 4:** Gradient accents -- amber-to-amber-light gradient on CTA buttons, navy-to-navy-light gradient on header, subtle gradient borders on cards
- **Variation 5:** Warm gray backgrounds -- replace #F8FAFC with #F5F0EB (warm cream) for alternating sections, warmer overall feel
- **Variation 6:** Bold typography -- larger H1 (56px), heavier card headings (700 weight), tighter letter-spacing on headings (-0.02em)
- **Variation 7:** Compact density -- 48px section spacing (tighter), smaller card padding (12px), denser grid gaps (16px), more content visible above fold
- **Variation 8:** Generous density -- 96px section spacing, larger card padding (32px), wider grid gaps (32px), more breathing room
- **Variation 9:** Amber emphasis -- amber top border on all cards (3px), amber left-border accent on testimonial cards, amber underline on section headings
- **Variation 10:** Minimal/clean -- no card shadows (border-only cards with 1px gray-200 border), flat buttons (no shadow), cleaner/flatter aesthetic

Each file should have a heading at the top: "Theme Variation N: [description]" so the user can quickly identify each.

Use Google Fonts CDN for Cormorant and Cormorant Garamond:
```html
<link href="https://fonts.googleapis.com/css2?family=Cormorant:wght@400;500;600;700&family=Cormorant+Garamond:wght@400;500;600;700&display=swap" rel="stylesheet">
```

Body text must be Cormorant Garamond at 18px minimum. Headings must be Cormorant.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between icon and label |
| sm | 8px | Compact element spacing, form field internal padding, badge padding |
| md | 16px | Default element spacing, card padding, button horizontal padding |
| lg | 24px | Section inner padding, card content spacing, form field vertical gaps |
| xl | 32px | Layout gaps between grid items, header/footer inner padding |
| 2xl | 48px | Section vertical padding on mobile (`--spacing-section-sm` in @theme) |
| 3xl | 80px | Section vertical padding on desktop (`--spacing-section` in @theme) |

**Intentional scale extensions:** The 80px (3xl) token and the 44px touch-target minimum (see Exceptions below) fall outside the standard 8-point scale reference set (4, 8, 16, 24, 32, 48, 64). Both are retained as intentional extensions for the following reasons:
- **80px (3xl):** Matches the RESEARCH.md `--spacing-section: 5rem` value established for desktop section vertical padding. 64px is too tight for full-width hero/CTA/section separations on desktop viewports; 80px provides the breathing room this layout requires. 80 is a multiple of 4 and 8.
- **44px touch-target minimum:** Required by WCAG 2.2 Level AA Target Size (Enhanced) criterion. 44 is a multiple of 4. This value applies only to interactive element minimum dimensions, not to layout spacing tokens.

Exceptions:
- Touch targets: 44px minimum height for all tappable elements (phone CTA button, form submit, hamburger menu icon, nav links on mobile). This ensures WCAG 2.2 Level AA target size compliance.
- Hero section: 100vh minimum height on desktop, auto on mobile.

**Source:** Default 8-point scale, adapted with 80px (3xl) matching RESEARCH.md `--spacing-section: 5rem` value.

## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 18px (text-lg) | 500 (medium) | 1.6 | Cormorant Garamond |
| Subheading (H3) | 24px (text-2xl) | 600 (semibold) | 1.3 | Cormorant |
| Heading (H2) | 32px (text-3xl) | 700 (bold) | 1.2 | Cormorant |
| Display (H1) | 48px (text-5xl) | 700 (bold) | 1.1 | Cormorant |

**Scale notes:**
- Body text MUST NOT drop below 18px on any viewport. The formal type scale contains exactly 4 sizes.
- **14px exception (not a named scale step):** 14px (`text-sm`) may be used as a one-off size exclusively for form field labels, badge text, footer fine print, and geographic cluster tags. It is NOT part of the formal 4-step type scale above. When 14px is used, differentiate it from body text via reduced opacity (`text-gray-500` or `opacity-75`) in addition to the smaller size. Never use 14px for readable body paragraphs.
- H1 on mobile scales down to 36px (`text-4xl`) via responsive utility: `text-4xl md:text-5xl`.
- H2 on mobile scales down to 28px (`text-[28px]`) via responsive utility: `text-[28px] md:text-3xl`.
- All heading sizes use Cormorant (not Cormorant Garamond).
- Font weights limited to 2 per family: body uses 500 (regular) and 600 (semibold for emphasis); headings use 600 (subheadings) and 700 (main headings, display).

**Source:** FNDN-04 (18px min body), CLAUDE.md (Cormorant Garamond medium weight body, Cormorant headings, 18px min).

## Interaction Contracts

### Sticky Header
- Position: `sticky top-0 z-50`
- Background: Navy (#1B2A4A) with `backdrop-blur-sm` as fallback if semi-transparent
- On scroll: No visual change (solid navy, no shrink/grow)
- Desktop: Logo (left) | Nav links center (Services dropdown, Locations dropdown, Guides, About, Contact) | Phone CTA button (right, amber)
- Mobile: Logo (left) | Phone CTA button (center-right, compact "Call" label) | Hamburger icon (right)
- Mobile menu: Full-screen overlay with navy background, z-40, slide-in from right, close on backdrop click or X button

### Navigation Dropdowns
- Trigger: Hover on desktop, tap on mobile
- Appearance: White background, shadow-lg, rounded-lg, z-50 (child of header)
- Items: 18px font, navy text, hover amber-light background
- Desktop: Appears below nav item, max-width 280px
- Mobile: Expands inline within mobile menu (accordion pattern, not separate dropdown)

### Card Hover (Service Cards, Municipality Cards)
- Default: White background, shadow-sm, rounded-lg, border-transparent
- Hover: shadow-md, border-amber (1px), translate-y-[-4px], transition-all duration-300
- Focus-visible: 2px amber outline offset by 2px (keyboard accessibility)

### Contact Form States
- **Idle:** White input fields with 1px gray-300 border, rounded-md, 18px body text, focus: border-amber + ring-2 ring-amber/20
- **Submitting:** Submit button shows "Sending..." text, opacity-50, cursor-not-allowed, disabled
- **Success:** Form replaced by centered green-50 background panel: "Thank You!" heading (H3, navy), "We'll call you within 1 hour." body text, amber phone CTA button below
- **Error:** Red-600 text error message appears above submit button. Input fields with validation errors get border-red-600. Error message format: "{problem}. Please call us directly at (973) 555-0100."
- **Validation:** HTML5 native validation (required, type="email", type="tel"). No JavaScript validation library.

### Phone CTA Button
- All viewports: `<a href="tel:+19735550100">` wrapping amber button
- Desktop (md+): Full display "(973) 555-0100" with Phone icon (lucide)
- Mobile (<md): "Call" label visible, full number in sr-only span
- Hover: amber-dark background
- Active: Scale down to 0.97 for tactile feedback

### Emergency CTA Banner
- Full-width amber (#D97706) background
- White bold text, centered
- Contains: Urgent headline + phone number + white CTA button (white bg, amber text)
- CTA button hover: slight scale-up, shadow-md

### Mid-Page CTA Bars
- Full-width navy (#1B2A4A) background
- White text, centered: "Need a roofing estimate? Call (973) 555-0100 or"
- Inline amber "Get Quote" button (small variant)
- Placed between major homepage sections (after ServicesGrid, after ServiceAreas)

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Focus visibility | All interactive elements: 2px amber outline, 2px offset, visible on :focus-visible only |
| Skip navigation | Hidden "Skip to main content" link as first focusable element, visible on focus |
| Touch targets | Minimum 44x44px for all tappable elements |
| Color contrast | Navy (#1B2A4A) on white: 12.6:1 (AAA). White on amber (#D97706): 3.1:1 (AA large text only -- used only for buttons with bold 18px+ text). White on navy: 12.6:1 (AAA). |
| Alt text | All images have descriptive alt (not filenames). Decorative icons use aria-hidden="true". |
| Form labels | Every input has an associated `<label>` element. Required fields marked with aria-required="true". |
| Heading hierarchy | Single H1 per page, strict H1 > H2 > H3 order, no skipping |
| Keyboard navigation | Tab order follows visual order. Dropdown menus navigable with Arrow keys. Escape closes dropdowns and mobile menu. |
| Reduced motion | `motion-reduce:` prefix on all transition/animation utilities (translate-y hover, transition-all) |
| Screen reader | Phone number: sr-only full number on mobile compact view. Star ratings: aria-label="5 out of 5 stars". |
| Hamburger menu button | `aria-label="Open navigation menu"` on the hamburger icon button. `aria-expanded` toggles between `"true"` and `"false"` to reflect menu state. |
| Mobile menu close button | `aria-label="Close navigation menu"` on the X (close) button within the mobile overlay. |

**Source:** SEO-02 (heading hierarchy), SEO-08 (alt text), WCAG 2.2 Level AA requirements.

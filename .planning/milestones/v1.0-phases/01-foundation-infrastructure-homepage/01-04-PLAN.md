**3. Create `app/api/contact/route.ts` (per D-17, LEAD-03):**

POST-only API Route Handler. Accepts JSON body with `name`, `phone`, `email`, `serviceType`, `message`.

```typescript
import { NextRequest } from 'next/server'

interface ContactFormData {
  name: string
  phone: string
  email: string
  serviceType: string
  message: string
}

export async function POST(request: NextRequest) {
  try {
    const body: ContactFormData = await request.json()

    // Server-side validation
    if (!body.name?.trim() || !body.phone?.trim() || !body.email?.trim()) {
      return Response.json(
        { error: 'Name, phone, and email are required.' },
        { status: 400 }
      )
    }

    // Basic email format check
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(body.email)) {
      return Response.json(
        { error: 'Please provide a valid email address.' },
        { status: 400 }
      )
    }

    // Forward to GoHighLevel webhook (server-only, never exposed to client)
    const ghlWebhookUrl = process.env.GHL_WEBHOOK_URL
    if (!ghlWebhookUrl) {
      console.error('GHL_WEBHOOK_URL not configured')
      return Response.json(
        { error: 'Form submission failed. Please call us directly at (973) 555-0100.' },
        { status: 500 }
      )
    }

    const ghlResponse = await fetch(ghlWebhookUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        firstName: body.name.split(' ')[0],
        lastName: body.name.split(' ').slice(1).join(' ') || '',
        phone: body.phone,
        email: body.email,
        source: 'Website Contact Form',
        tags: ['website-lead', body.serviceType].filter(Boolean),
        customField: {
          service_requested: body.serviceType,
          message: body.message,
        },
      }),
    })

    if (!ghlResponse.ok) {
      console.error('GHL webhook failed:', ghlResponse.status, await ghlResponse.text())
      return Response.json(
        { error: 'Form submission failed. Please call us directly at (973) 555-0100.' },
        { status: 500 }
      )
    }

    return Response.json({ success: true })
  } catch (error) {
    console.error('Contact form error:', error)
    return Response.json(
      { error: 'Something went wrong. Please call us directly at (973) 555-0100.' },
      { status: 500 }
    )
  }
}
```

Key security points:
- GHL_WEBHOOK_URL has NO `NEXT_PUBLIC_` prefix (server-only, per RESEARCH.md Pitfall 5)
- Server-side validation before forwarding
- Trim inputs to prevent whitespace-only submissions
- Basic email regex check
- Detailed error logging server-side, generic messages client-side
- No sensitive data in client-facing error responses

```typescript
async function handleSubmit(e: FormEvent<HTMLFormElement>) {
  e.preventDefault()
  setStatus('submitting')
  const formData = new FormData(e.currentTarget)
  const data = {
    name: formData.get('name') as string,
    phone: formData.get('phone') as string,
    email: formData.get('email') as string,
    serviceType: formData.get('serviceType') as string,
    message: formData.get('message') as string,
  }
  try {
    const res = await fetch('/api/contact', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    })
    if (res.ok) {
      setStatus('success')
    } else {
      const err = await res.json()
      setErrorMessage(err.error || 'Something went wrong.')
      setStatus('error')
    }
  } catch {
    setErrorMessage('Network error. Please call us directly at (973) 555-0100.')
    setStatus('error')
  }
}
```

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-04-02 | Tampering | Contact form data | mitigate | Server-side re-validation in route.ts -- do not trust client-side HTML5 validation alone. Sanitize by only extracting known fields from body (name, phone, email, serviceType, message). |
| T-01-04-03 | Information Disclosure | GHL_WEBHOOK_URL | mitigate | Environment variable has NO `NEXT_PUBLIC_` prefix. Only accessed in server-side route.ts. Never sent to client. Client submits to /api/contact, not directly to GHL. |
| T-01-04-04 | Denial of Service | /api/contact spam | accept | No rate limiting in Phase 1. GHL webhook handles dedup. For v2, consider adding rate limiting middleware (e.g., Vercel Edge Config or Upstash Redis rate limiter). Acceptable for initial rank-and-rent site with low traffic. |

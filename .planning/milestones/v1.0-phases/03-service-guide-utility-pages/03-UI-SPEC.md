## Spacing Scale

Inherited from Phase 1 + Phase 2 without modification:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, process step numbering padding |
| md | 16px | Default element spacing, card padding, benefit card icon gap |
| lg | 24px | Section inner padding, card content spacing, TOC item spacing |
| xl | 32px | Layout gaps between grid items, gap between service cards |
| 2xl | 48px | Section vertical padding on mobile (`py-section-sm`) |
| 3xl | 80px | Section vertical padding on desktop (`py-section`) |

Exceptions:
- Touch targets: 44px minimum height for all tappable elements (FAQ toggle buttons, CTA buttons, phone links, TOC links on mobile, mega menu items).
- Hero section: `min-h-[70vh]` on service pages (consistent with location pages). `min-h-[50vh]` on guide pages (article-oriented, hero is introductory, not immersive). Utility pages: no hero minimum height constraint (content-first layouts).
- Sticky TOC sidebar: 20px top offset from viewport (`top-20`) to clear the sticky header.

**Source:** Phase 1 + Phase 2 UI-SPEC spacing scale. Hero height exceptions are Phase 3 specific per page type role.

## Typography

4 font sizes, 2 font weights. Inherited from Phase 2, unchanged.

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 18px (text-lg) | 500 (medium) | 1.6 | Cormorant Garamond |
| Subheading (H3) | 24px (text-2xl) | 700 (bold) | 1.3 | Cormorant |
| Heading (H2) | 32px (text-3xl) | 700 (bold) | 1.2 | Cormorant |
| Display (H1) | 48px (text-5xl) | 700 (bold) | 1.1 | Cormorant |

**Responsive breakpoint adaptations (same 4-size scale, not additional sizes):**
- H1: 48px desktop, 36px mobile (`text-4xl md:text-5xl`).
- H2: 32px desktop, 28px mobile (`text-[28px] md:text-3xl`).

**Phase 3 typography notes:**
- Service page H1: `"{Service Name} in Passaic County, NJ"` -- 48px desktop, 36px mobile.
- Guide page H1: `"{Guide Title}"` -- 48px desktop, 36px mobile.
- Utility page H1: `"About Us"`, `"Contact Us"`, etc. -- 48px desktop, 36px mobile.
- Process step number: 48px (`text-5xl`) weight 700, Cormorant, `text-amber/20` (faded accent for decorative numbering).
- Process step title: 24px (`text-2xl`) weight 700, Cormorant (H3 level).
- Benefit card title: 24px (`text-2xl`) weight 700, Cormorant (H3 level).
- Table of Contents link text: 18px (`text-lg`) weight 500, Cormorant Garamond. Active link: weight 700, `text-amber`.
- Read time badge: 14px (`text-sm`) weight 500, `text-gray-500`. Same exception category as Phase 1 (not a named scale step).
- Expert Tips list item: 18px (`text-lg`) weight 500, standard body styling.
- Legal page body (Privacy/Terms): 18px body standard, `text-gray-700`, paragraph spacing `mb-4`.
- Mega menu category heading: 14px (`text-sm`) weight 700, `text-gray-500 uppercase tracking-wider`. Same 14px exception as Phase 1.
- Mega menu service link: 18px (`text-lg`) weight 500, `text-navy hover:text-amber`.

**Source:** Phase 2 UI-SPEC typography scale. Phase 3 applies existing scale to new page types. 14px exception carried from Phase 1 for meta/label text.

## Interaction Contracts

### FAQ Accordion (ServiceFAQ, GuideFAQ)

Identical to CityFAQ interaction pattern established in Phase 2:

| State | Visual |
|-------|--------|
| All collapsed (default) | Question text visible, chevron pointing down, answer hidden |
| Item opening | Chevron rotates 180deg (duration-200), answer panel expands with smooth height transition (duration-300) |
| Item open | Chevron pointing up (amber color), answer text visible with `pb-5` |
| Item closing | Reverse of opening -- chevron rotates back, answer collapses |
| Hover on question | `hover:bg-gray-50` subtle highlight on question row |
| Focus-visible | 2px amber outline, 2px offset on question button |
| Reduced motion | `motion-reduce:transition-none` on chevron rotation and answer panel height |

**Keyboard:** Tab navigates between question buttons. Enter/Space toggles. No arrow key navigation.

### Table of Contents Scroll Tracking

| State | Visual |
|-------|--------|
| Default | First section highlighted as active |
| Scrolling | Active section updates as user scrolls past H2 headings. `IntersectionObserver` with `rootMargin: '-80px 0px -70% 0px'` (accounts for sticky header, activates when heading enters top 30% of viewport). |
| Click on TOC link | Smooth scroll to target H2 (`scroll-behavior: smooth` or `element.scrollIntoView({ behavior: 'smooth' })`). |
| Active indicator | Amber left border (`border-l-2 border-l-amber`) + `text-amber font-bold` |
| Transition | `transition-colors duration-200` on link text color change |
| Reduced motion | `scroll-behavior: auto` when `prefers-reduced-motion: reduce` |

### Table of Contents Mobile Toggle

| State | Visual |
|-------|--------|
| Collapsed (default) | "Table of Contents" text + `ChevronDown` icon. `bg-gray-light rounded-[var(--radius-card)] p-4` |

| Interaction | Click/tap toggle button. `aria-expanded` on toggle button. |

### Mega Menu (Desktop)

## Accessibility Contract

Inherited from Phase 1 + Phase 2 plus Phase 3 additions:

| Requirement | Implementation |
|-------------|----------------|
| FAQ keyboard access | ServiceFAQ and GuideFAQ inherit CityFAQ keyboard pattern: `<button>` with `aria-expanded`, `aria-controls`, answer `role="region"`, `aria-labelledby`. |

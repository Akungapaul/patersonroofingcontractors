**components/sections/TableOfContents.tsx** (Client component -- `'use client'`):

Props: `{ sections: readonly { id: string; title: string }[] }`

Implement two modes:
1. Desktop (lg+): rendered in sidebar, use `sticky top-20` positioning
2. Mobile (<lg): collapsible panel

Use `useState` for `activeId` (defaults to `sections[0]?.id`) and `isOpen` for mobile toggle.

IntersectionObserver setup in `useEffect`:
```typescript
const observer = new IntersectionObserver(
  (entries) => {
    entries.forEach((entry) => {
      if (entry.isIntersecting) {
        setActiveId(entry.target.id)
      }
    })
  },
  { rootMargin: '-80px 0px -70% 0px' }
)
sections.forEach(({ id }) => {
  const el = document.getElementById(id)
  if (el) observer.observe(el)
})
return () => observer.disconnect()
```
